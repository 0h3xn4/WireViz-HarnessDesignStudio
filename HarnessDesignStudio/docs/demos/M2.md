# M2 demo note: Qt block-diagram editor

**Done** (the UX gate in `M2-gate.md` was approved by the owner)
- **Headless core additions** (`core/edit.py`, `checks.py`, `imports.py`, `recovery.py`): unit templates, deterministic placement and zones, compatibility rules (Guided: unit level, Expert: exact connector), add/delete/rename/redundant copy/complete-chain operations, logical findings with safe fixes and waivers, CSV/XLSX import planning with per-row results, autosave journal. - **Files and safety**: new/open/save/save-as, project lock with read-only fallback, autosave journal with restore after a crash, reload prompt when files change on disk, recovery-mode banner and issue list, read-only banner for newer formats, unsaved-changes prompt, settings (mode, theme, scale, last project).
- **Packaging**: the frozen app passes a real end-to-end self-test (open sample, add unit, connect, save, reload) normally and inside a network-less namespace; the CLI (`validate`, `check`, `migrate`) ships inside the package (`cli/`).
- Open item closed from M1: the CLI is now in the frozen package.

**Tested**: 295 tests pass (1 skipped: needs a non-root user). 40 GUI journey tests (pytest-qt, offscreen), 5 stress-size performance guards, 21 core tests for edits/checks/imports/journal, plus the M1 suite, the 35 prototype browser tests and the offline/architecture tests. Core coverage 96.8% (gate 90%). The M1-format fixture proves old projects load unchanged.

**UX review**: 16 findings in `docs/UX.md` section 12; 10 fixed with tests (including 6 high severity found only by rendering the screens), 6 open (chip overlap in dense diagrams, hint height jump, small canvas at 150%+, hidden-panel hint, canvas screen-reader support, 100 ms worst case).

- Mock data in the sample (mini3) is example data; the starter library has no ratings or masses.
