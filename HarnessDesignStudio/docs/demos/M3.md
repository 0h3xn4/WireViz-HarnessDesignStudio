# M3 demo note: harness generation and independent verifier

**Done**
- **Generation** (`core/generate/`): segmentation (per connector pair by default, per unit pair or per zone pair by configuration; nominal, redundant and pyro never mixed), pin allocation (locks, power first, adjacent pairs, configurable gap, earlier allocation kept), wiring rule (TX to RX by position, same-name for passive and one-directional signals), shields by interface type, deterministic IDs, wire sizing from configured tables only, lengths from routing segments (with CSV import planning), mass from library data, regeneration merge with a change report, provenance for Explain.
- **Safety**: plan-then-apply (nothing changes until the user accepts the preview); one undo step; released harnesses frozen; locked wires and pins and manual harnesses never touched; cancel changes nothing.
- **Independent verifier** (`core/verify.py`): recomputes the expected connections from the interfaces and compares them with the wires (missing, extra, swapped, duplicated, pin reuse, bad mates, outdated outputs). Shares only the hash comparison with the generator.
- **Reference projects**: `sat15` (15 units, 24 interfaces, redundant chains; golden fixture) and a stress project generator (200 units, 2,000 interfaces).
- **CLI**: `harness generate DIR` (does not save if errors) and `harness verify DIR`.
- **Editor**: Generate button is live, runs in a worker thread with progress and Cancel, shows a preview (counts, findings, placeholders in use), then fills the Harness plans tab: status (not generated / up to date / out of date), the independent check result, harness list, wire list, and "Why is it like this?" from the recorded reasons.

**Tested**: 351 tests pass (1 skipped: needs a non-root user). New: regeneration byte-identical (plus a Hypothesis property test), stable IDs, frozen and locked handling, cancel, verifier mutation tests, golden `sat15`, building-block tests (sizing with test-only numbers, pins, lengths, mass, modes), CLI, 8 GUI tests. Core coverage 94% (gate 90%). Ruff and mypy strict clean.

**Acceptance (docs/PLAN.md)**: byte-identical regeneration yes; verifier clean on `mini3` and `sat15` yes; stress project (2,000 interfaces, 140 harnesses, 20,000 wires): plan 2.0 s, apply 0.0 s, verify 0.6 s, replan 2.1 s on this machine (target under 10 s) yes.

**Placeholders in use (results say so)**: no derating numbers, so wire gauges stay "pending"; no resistivity, service loop, pin gap, margin or shield-end values; no part masses. List: `docs/PLACEHOLDERS.md`. D-10 (boundary rule) and D-11 (derating numbers) still need the owner.

**UX targets**: the preview-then-undo flow and Explain exist; usability tests (SUS, 90% task success) still need real users. Open UX items: the Harness plans tab is a table view, not a diagram of the harness (M5); wire locking is in the model but has no toggle in the editor yet.

**Limits and risks**
- Multi-drop interfaces (more than two units) are skipped with a warning.
- Spare-pin fraction and the length-import screen are not implemented in the editor (length import exists as tested core code).
- Windows and Rocky 8 builds are still untested here.
