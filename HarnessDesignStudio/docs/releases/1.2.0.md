- **Now for Windows and macOS too.** Download the setup program or the portable `.zip` for Windows 10 and 11, or the disk image for macOS 13 and newer (one for Apple Silicon, one for Intel). They install for your user, need no administrator rights and no network, and behave like the Ubuntu packages.
- **Same results everywhere.** Run the same commands on Windows, macOS or Ubuntu and you get byte-identical files. The whole test suite of about 2,800 tests now passes on all three systems.
- **Fixes found on the way.** The "this project is already open" protection works on Windows; the editor shows its bundled fonts there; Return, F2 and Tab do the same in tables and dialogs on every system; and a damaged workbook is reported as a finding instead of a crash.
- **Not signed.** The packages carry no code-signing certificate, so Windows and macOS warn on the first start (the install steps below say what to click). Compare the SHA-256 value of your download with the table.
- **Unchanged.** The design model, the file format, the 34 design rules and the generated files are the same as in 1.1.0, apart from the tool version and the model hash that records it.
