- **The documents are brought up to date.** A page-by-page check of the manual, the tutorial, the help pages, the reference pages and the notes for developers against the program and against real runs of the commands they show. Wrong statements were corrected (package names, the Systems engineer's menus, a menu path, the number of files `templates` writes, the flatsat mass, buttons that do not exist, sample outputs that no longer matched) and features of 1.8.0 to 1.11.0 that pages left out were added (pin direction, the connection list, `conductors` in the BOM and the mass, a waiver tied to its finding, the coax rule, the Requirement and Signal/Interface columns, the library and subsystem commands). Fifteen pictures of the manual were made again.
- **The guide in the program (F1) says what the program does now.** It is built into the packages, so this is the one document a user of 1.11.0 could not get from the repository. It has 15 corrections: which role opens on the Next step page, the menu entries the Systems engineer role hides, a button that does not exist, the status chips, the files the export writes, the new table columns, the coax rule, waivers that no longer fit and three command options.
- **Unchanged.** The program, the file format, the design rules (still 39) and the written files are as in 1.11.0, apart from the tool version in the stamp and the model hash that follows from it.
- **Not in this release / for you to know.** Nobody looked at the program on a real display: steps in the app were checked against the program's texts and the pictures are drawn without a screen. Still open: the owner's decisions on the standards and quality process, variants and a sharded `links.json`, and the soldering questions for the AIT engineers (`docs/OPEN_DECISIONS.md`). Set `conductors` on your own pair parts (1.11.0): the tool does not guess it. Nobody has signed this release off as the owner; this page is not a statement of compliance.
