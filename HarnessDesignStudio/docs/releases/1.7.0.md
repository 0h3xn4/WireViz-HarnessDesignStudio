- **A build workbook for every harness.** `harnesses/W001/W001_build.xlsx` is an Excel file to build the harness from: a *Start here* sheet (ready to build, yes or no, and what is still open), the cut list in cutting order with the wire colours, a block for every connector pin by pin with tick columns, the parts, the labels and a test sheet with empty columns for the measured values, the initials and the date. It prints on A4 landscape, has no formulas and is the same bytes for the same design.
- **The PDF drawings are optional.** `harness-design-studio export` no longer writes the drawings of the harnesses unless you add `--drawings` (in the app: the check box *Include the PDF drawings* in the Export window). The block diagram, the overview and every list are written as before.
- **The build data a technician needs.** The strip length at each end of a wire, the contact on each pin and the crimp tool of a contact, and the sleeving, heat shrink, labels and backshells of a harness. Enter them in the editor or read them from a table with `harness-design-studio import-build-data`; the workbook shows them and marks what is missing as *to fill in*. Nothing is computed from them and Generate keeps what you entered.
- **A simple workspace.** A *Next step* page names one thing to do at a time, with one button, and in the Simple workspace the project tree, the inspector and the Problems panel start closed. A first run opens in Simple; anyone who already has settings keeps the full editor, and *Workspace: Simple or Full* in the View menu switches. Nothing is removed: every hidden thing keeps its menu entry, shortcut and palette entry. The plain-words stage was dropped and the first-project stage is not built yet.
- **Unchanged for existing work.** No new file field is written while it is empty: a project saved by 1.6.0 opens as it is, the file format is the same, and every other generated file of an existing project is byte-identical apart from the tool version it records.
