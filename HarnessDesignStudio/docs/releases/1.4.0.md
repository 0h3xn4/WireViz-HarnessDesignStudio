- **Edit every wire.** The new *Edit wire* tab sets the gauge, type, colour and length of one or several wires, gives a wire a label and a note, and draws a wire between any two pins. Generate keeps what you set and what you drew, and tells you when it cannot.
- **Several wires on one pin, twisting and shielding.** Two wires may share a pin (a new design rule names such a pin), and selected wires can be twisted or shielded together as a pair, quad, coax or overall shield.
- **A function on every pin, labels on connectors and harnesses.** Free text per pin (in the Devices tab, in pasted blocks and in the pinout import), labels that `labels.csv` prints, and the crimp or solder termination in the pinout lists.
- **Who changed it last.** Revisions shows the last commit of the Git repository around the project folder, read without running Git.
- **Reuse a device in another project.** Save a device with its pinouts to a device library file and add it to another project; the parts import also reads InvenTree export files, offline.
- **Unchanged for existing work.** A project that does not use the new fields keeps byte-identical files and outputs, apart from the tool version they record (checked file by file: 567 files of the four examples). Projects that use the new fields cannot be opened completely by 1.3.0.
