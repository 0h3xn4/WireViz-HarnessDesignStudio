- **Define a device down to each pin.** The new **Devices** tab (Ctrl+6) lets you create a device, give it connectors and pins, and say which interface each pin carries. Edit in place or paste from a spreadsheet, or import a pinout from CSV or Excel (**File > Import > Import device pinout…**, or `harness-design-studio import-pinout`). `export-pinout` writes it back out, and every action is one undo step.
- **A new editor layout.** Tabs for Diagram, Harness, Lists, Checks and Releases; a project tree and an inspector with *Why* and *Problems*; a light, dark or system theme; state chips that never rely on colour alone; **Fix all** for the one-click fixes; and a Ctrl+K command search.
- **Clearer diagrams.** Select several items at once, find with Ctrl+F, snap to a grid, readable link labels, and a different picture for LVDS and RS-422.
- **New command names.** `harness-design-studio` and `harness-design-studio-gui`. The old `harness` and `harness-gui` still work.
- **Results unchanged.** The design model, the file format (projects saved by 1.0.0 open as they are), the 34 design rules and the generated files are the same as in 1.0.0, apart from the tool version and the model hash that records it.
- **Status.** This release has not been signed off by the owner (`docs/RELEASE.md`, step 14).
