- **A new look and a calmer window.** A navigation rail on the left (Home, Model, Checks, Drawings, Outputs, Revisions, Settings), one top bar with the three steps Generate, Check and Release, a Problems panel and a status bar that shows what runs. Light and dark themes that switch at once, with the bundled Inter and JetBrains Mono fonts.
- **Tables that work like a spreadsheet.** Paste a block from Excel into the Interfaces or the new Units table, edit several rows at once, press Enter to edit and Esc to cancel; a paste is one undo step.
- **The window does not freeze any more.** In a very large project every edit used to wait about 11 seconds for the rule check; it now takes under half a second. Large imports are read in the background.
- **One import wizard** for all six kinds of file, a list of the exported files with their SHA-256 and whether they still match the export, tinted differences between revisions, and a Settings area with shortcuts, About and licences.
- **Unchanged.** The design model, the file format, the 34 design rules, the command line and the generated files are the same as in 1.2.0, apart from the tool version they record (checked file by file: 567 files of the four examples).
