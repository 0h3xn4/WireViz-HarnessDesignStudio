- **Make a harness from nothing.** *New harness…* (Drawings area, Edit menu, Ctrl+Shift+H) makes an empty harness with no interface behind it. The new *Connectors* tab adds its connectors (from the parts library, or the other half of a unit's connector with its pins, gender and keying), sets what each pin does and how it is terminated, and the wires are drawn in *Edit wire*. Checks, drawings, lists, review and release work as for any harness, and Generate leaves it alone.
- **Starts without hassle on Linux.** The package carries its own Python and Qt; if the computer lacks a graphics or window-system library, or has no desktop session, the editor now says which one and the exact `sudo apt install` line, in the terminal or in a small window, instead of closing silently. `harness-design-studio-gui --check-system` runs only that check, and `install.sh` warns.
- **Checked on a bare machine.** Every build now runs the packages with no Python in the environment, and the Linux package on a plain Ubuntu with only three system libraries.
- **Unchanged for existing work.** No new file field: a project saved by 1.4.0 opens as it is, and every generated file of an existing project is byte-identical apart from the tool version it records.
