- **No more wrong "two outputs drive against each other" errors.** Connections between analog, discrete, LVDS, pyro and I2C clock pins were reported as an output joined to an output, which cannot be waived. They are checked correctly now, and the program pairs them. A device that is joined only by a connection is no longer called "not connected to anything yet", and a heater connection (`HTR+`, `HTR-`) is no longer called "power without return".
- **Vendor-style pin names pair correctly, and TX is never paired with TX.** `UART_TX` meets `UART_RX`, `SPW_DOUT+` meets `SPW_DIN+`, `TX_P` meets `RX_P`, `MOSI` meets `MISO`. Two equal transmit names, or two equal receive names, are never paired by the program; if you make such a pair yourself you get a warning.
- **A harness made from a connection is checked against it.** If a wire of that harness is moved, added, removed or relabelled, `validate`, `check`, `verify`, the design rules and `export` stop and say so in plain words.
- **Two plugs on one connector are reported.** A device connector with two cable plugs on it, or a pin wired by two harnesses, is reported when you check the project, and Generate reports a second plug. A connection or harness onto a connector that already has a plug, or onto a pin an interface uses, is refused with a reason.
- **"Not checked" instead of "pass".** A design rule that is ready to run but has nothing to look at (no interface with a current or a voltage, no EMC class) now says "not checked" with a plain note. Wires with no interface (a harness drawn by hand or made from a connection) get a note that the current, voltage-drop and bundle checks did not run for them. The build workbook no longer says a bare "Ready to build: yes" when the values rest on placeholder configuration: it says so and lists the placeholder files.
- **The library no longer overwrites a different device without asking.** Saving a device whose ID is taken by a different device asks: Replace, Save as a new ID, or Cancel (`export-devices` refuses unless you give `--replace`). One damaged or hand-edited file in the library folder no longer hides the others: it is listed with a plain sentence and, for a JSON error, the line and column. A device whose pins use a cable contact part, or that was renamed, can be added from the library.
- **Tab leaves every table.** A keyboard user with a row selected in the pair table of the Link connectors window, in the library list or in a main-window table could not reach the buttons below. Now Tab leaves the table (tables where Tab moves from cell to cell keep that and leave with Ctrl+Tab). Connection lines on the diagram can be reached with Tab; Space selects one and Enter opens the Link connectors window.
- **Faster edits in big projects.** About 30 % faster for one edit at 150 devices, over 40 % at 300.
- **Command line.** On Windows the output is UTF-8 when it is redirected or piped, so `drc project > report.md` works with names that contain Ω or ✓. Importing data the project already holds (pinouts, parts, KiCad netlists, build data) says "Already up to date." and exits 0, so a build can import the same file every time.
- **Six stale statements in the documents are corrected** (where interface types are kept, what a new project ships, how two people merge, which role opens on the Next step page, the "Why" excerpt of Getting Started, what the command line can add).
- **Unchanged for existing work.** No new feature, no change of the file format, the design rules stay 39. The files and outputs of a project that does not meet one of these cases are byte-identical to 1.8.0, apart from the tool version they record (checked file by file). The one written text that changes for projects on placeholder configuration is the line *Ready to build* of the build workbook.
- **Not in this release / for you to know.** The audit of 1.8.0 (`docs/AUDIT_1.8.0.md`) lists what is still open: buses, variants, import of existing wire lists, command-line versions of the 1.8.0 features (connections, editing a connector, a group or all wires), and a complete path for the Systems engineer from a blank project to a released harness. Nobody has watched the screens on a real display. The owner has not signed this release off. The packages are not signed.
