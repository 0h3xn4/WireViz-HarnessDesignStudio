This is the **first full release with signed packages**, and the full release of what the release candidate 1.17.1rc2 tested. **It supersedes the releases 1.0.0 to 1.17.0:** they carry no licence text, no notices of the third-party components and no signature, and they cannot be completed. Use this release and the ones after it.

The program is the same as in 1.17.1rc2. Everything that changed since 1.17.0 is listed here.

### The main changes

- **A licence.** The code, tests, tools and documents are licensed under GPL-3.0-only. `LICENSE`, `NOTICE` and `THIRD_PARTY_NOTICES.txt` are inside every package and the licence text is in the About window. A short notice (the name and version of the tool, and that the result must be verified) is in every file the tool writes; the files differ from those of 1.17.0 only by that notice and the version.
- **Signed packages.** Every package, `SHA256SUMS` and the SBOMs are signed with Sigstore and carry a build provenance attestation. The section *Check your download* below has the commands to check them.
- **What is inside the packages.** A software bill of materials and an inventory of the third-party components of the Linux and the Windows package, and the source of the LGPL and GPL components (Qt for Python, Qt and the Ubuntu libraries), are attached to this page. The Qt source is checked against the SHA-256 sum that download.qt.io publishes, and a download of the source is tried again after a network error.
- **The editor starts on Home and opens nothing by itself.** The Home page lists New project, Open project, the examples and your recent projects, newest first, so going on with your work is one click. **Clear list** empties the recent list (it asks first and touches no project folder).
- **No name is looked up.** A file holds a person's name only when you type it (`--author`, `--by`, the name field of a dialog) or set it in `HARNESS_AUTHOR`. The tool no longer takes the user name of the system or the name Git has; `review`, `release` and `revise` need `--by`. The lock file `.harness.lock` holds a random id of the installation instead of the computer's name.
- **The upstream WireViz files are as upstream wrote them**, and the text of the ECSS and ESCC standards is no longer in the repository (our assessment stays).
- **Loose cable ends** (steps M4a to M4c of the programme towards 2.0). A cable let go on empty ground is kept as a harness drawn by hand with a loose end; the written files name a loose end as an open end.
- **Evidence that the tool works offline.** A guide to check it yourself in 30 minutes, an audit of the built package, and a switch that turns Python plug-ins off on a computer.
- **A start-up notice and a self-check.** The first start shows the status, the intended use and the licence once. What was called the independent check is now called the self-check: it is a second routine of the same program, not a review by a person.

### Known limits

- **Nobody has checked the signature or the attestation from outside the release workflow yet.** Please check your download with the commands below and report what you see.
- **Nobody has looked at the new screens on a real display**, and the Windows packages were built and tested on GitHub's runners only. The Windows packages have no Windows code-signing certificate, so SmartScreen shows *Windows protected your PC*: **More info**, then **Run anyway**.
- **No compliance and no sign-off is claimed.** The configuration values are placeholders until your project supplies them.
