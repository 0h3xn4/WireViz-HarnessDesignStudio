- **macOS is gone.** The tool is supported on Ubuntu 24.04 and newer and on Windows 10 and 11, and this release has four packages: the `.deb`, the `.tar.gz`, the Windows setup program and the portable `.zip`. There is no macOS disk image any more; the images of 1.2.0 to 1.5.0 stay on their release pages, not maintained or tested.
- **A blank project says where to start.** The empty diagram now has the button **Add a device** (a unit with your own connectors and pins; the same as Edit > Add unit > Device…, Ctrl+Shift+N). The empty diagram, the empty link and unit lists and the narrow-window notice no longer send you to a palette that the 1.3.0 window does not have.
- **Unchanged for existing work.** No new file field: a project saved by 1.5.0 opens as it is, and every generated file of an existing project is byte-identical apart from the tool version it records.
