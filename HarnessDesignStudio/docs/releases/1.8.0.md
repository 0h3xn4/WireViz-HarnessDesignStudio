- **Start from the pinout: connect two connectors pin by pin.** **Edit > Link connectors…** (or the **Connect** tool and two devices) opens a window that proposes which pins go together from the signal names on the pins, never from their position (`TX` meets `RX`, `PWR` meets `PWR`). You look at the pairs, change them if you want, give a pin a role (power, return, ground, signal, shield, spare) and press *Link connectors*. Nobody has to pick an interface type first; what a connection carries (for example *CAN, 2 wires*) is worked out from the pins.
- **Check my connections, and Create harness only when you press it.** **Design > Check my connections** reviews every connection and changes nothing: a pin with a signal that no pair uses, an output joined to an output, two names that differ, power with no return. **Create harness** shows what it will add and makes the harness only after you agree; the program never makes one on its own.
- **Edit a connector, a group and all wires.** In the Connectors tab you set the part, gender, keying and name of a connector and the signal, role and details of its pins, also on a harness that Generate made (that connector then keeps your values until you give it back). **Change group…** changes the kind, the wires and the shield ends of a twisted pair, quad, coax or shield. **Edit all wires…** sets gauge, type, colour and length on all wires of a harness, or on the selected ones, in one step you can undo.
- **A library on a shared folder, with subsystems.** **File > Library folder…** names a folder, for example on a shared drive or in a Git checkout, and **File > Library…** opens a window to search it, look at an entry and add it to your project. The folder holds devices and **subsystems** (devices with the connections between them); adding a subsystem is one undo step and never replaces anything. Nothing is written into the folder unless you press *Save to library*. The program stays offline.
- **Ask for a number of devices.** **Number of these devices** in the Add device window, the Devices tab and the library window makes two, three or more of a device in one step. Two are the device and its redundant copy, exactly as before.
- **Two roles, Systems engineer and Electrical / AIT engineer.** The first start asks *Who are you working as?*, and **View > Role** changes the answer at once. The Systems engineer gets the lean window: the Next step page first, the side panels closed and only the tools for devices, connections and checks. The Electrical / AIT engineer sees every area and panel, as the editor always did. They replace the Simple and Full workspaces of 1.7.0. A role is a view, not a permission: it locks nothing and is not stored in a project.
- **Quick fixes from the workshop.** A new device asks for its name first and suggests the ID. The screen says *device* where it said *unit* (the project files and every written output keep the old word; the command line has `--device` and still accepts `--unit`). A switch, **Show problem notices**, hides the problem counts and badges (off for the Systems engineer). Export asks where to save a project that has no folder yet. The pin tables explain RTN (the return line).
- **39 design rules.** Four new rules read the connections (a pin nobody pairs, an output joined to an output, two different names in a pair, power with no return). A project without connections gets no new finding.
- **Unchanged for existing work.** No new file field is written while it is empty: a project saved by 1.7.0 opens as it is, the file format is the same, and the files and outputs of a project that uses none of the new things are byte-identical, apart from the tool version they record (checked file by file).
- **Not in this release.** Stage S4 of the simple workspace (a blank project that asks one thing at a time); command-line versions of the new edits (the command line cannot make a connection or edit a connector, a group or all wires); a lock for each single pin (an edited connector of a generated harness is locked as a whole). Nobody has watched the new windows on a real display; the screens were checked in a window started without a screen. Nothing measures whether the tool is easier to use, and the owner has not signed this release off. The packages are not signed.
