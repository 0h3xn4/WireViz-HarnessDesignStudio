# Prototype screenshots (history)

These 14 pictures show the **clickable HTML prototype** of October 2026 (mock data, a "Prototype" title bar). It was the review gate before the real editor was built, and it was replaced by the Qt editor. They are kept because [`../../UX.md`](../../UX.md) refers to them. They are **superseded by the pictures of the real editor in [`../qt/`](../qt/)**, which are rendered from the program by `python -m tools.gui_screenshots` and kept current.

The two folders use similar file numbers, but the files are not the same screens. Some prototype screens (`08-generate-preview.png`, `09-harness-plans.png`) have no counterpart in `qt/`; they show the earlier look, not the current one.
