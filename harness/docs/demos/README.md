# Milestone notes

These notes were written at the end of each development step. They are **history, not current behaviour**: numbers (tests, timings, rules, interface types), version names such as `rc1` and the platform remarks (Windows, Ubuntu 22.04) were true on the day and have since changed. For what the tool does now, read the [user guide](../guide/USER_GUIDE.md) and the [documentation index](../README.md).

| Note | What it records |
| --- | --- |
| [`M0.md`](M0.md) | The skeleton: folders, checks, the first package, the offline tests and the first software bill of materials. |
| [`M1.md`](M1.md) | The headless core: the model, the project folder format, integrity checks, undo and redo, the first commands. |
| [`M2-gate.md`](M2-gate.md) | The user-experience document and the clickable HTML prototype that the owner reviewed before the editor was built. |
| [`M2.md`](M2.md) | The Qt block-diagram editor, files and safety, and the first packaged app. |
| [`M3.md`](M3.md) | Harness generation and the independent verifier. |
| [`M4.md`](M4.md) | The design rule check, waivers and the report. |
| [`M5.md`](M5.md) | The outputs: drawings, tables, exports, stamps and stale detection. |
| [`M6.md`](M6.md) | Change control: review, release, revisions, locks, diff and the change log. |
| [`M7.md`](M7.md) | Polish: accessibility, the soak test, the user guide, the Ubuntu packages and release candidate 0.1.0rc1. |
